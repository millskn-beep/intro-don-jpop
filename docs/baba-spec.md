# アニソン・ババ抜き（仕様書）

## 目的
曲のカードでババ抜き。**同じ作品の曲2枚がペア**。どの曲とどの曲が同じ作品か、作品名の知識で見分けるのが腕の見せどころ（play `baba`）。3人以上。

## 1回の流れ（問題数＝回数。1回が1ゲーム）
1. **ペア出し（40秒）**：全員に曲カード（曲名・歌手が見える。作品名は見えない）が約5枚ずつ配られる。**同じ作品の曲2枚**を選んで「ペア」にして出す（2枚をタップ）。合っていれば捨てられて +300点、ちがうと −300点。全員が「出し終わり」を押せば先へ。
2. **ターン**：順番に、右隣の人の手札（裏向き）から1枚を引く（25秒。時間切れはランダムに引く）。引いたカードで新しいペアができたら、いつでも出せる（ペアはターンに関係なく、いつでも出せる）。
3. 手札がなくなった人から「上がり」。**最後までジョーカー（ババ）を持っていた人が負け**。
4. **結果**：上がった順に 1位 +3000／2位 +2000／3位 +1000、ババを持っていた人 −1000。ペアで増えた点・減った点も足す。

## 細かいきまり
- 配るペアは、すべて別のシリーズの作品（どのペアも作品名がかぶらない）。マイページの「もう聞きたくない」曲は配らない。
- 引いたカードは、手札のランダムな場所に入る（ババの場所が分からないように）。
- 自分の手札の曲は「聴く」で試聴できる。
- つながっていない人は、自動でペアを出して、ランダムに引く。
- チーム戦はなし。

## 実装
- server.js：startBabaRound・bbNextTurn・bbDraw・bbPair・bbFinish、socket `bbDraw`／`bbPair`／`bbReady`／`bbPreview`。手札は `bbHand`（本人だけ）、場は `bbPhase`（全員）。
- 画面：専用の窓（#babaPop）。
