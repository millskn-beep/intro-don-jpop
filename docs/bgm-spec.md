# アニソンBGM（仕様書）

## 目的
スマホで収録曲をBGMとして流し続ける（トップの「🎧 BGM」→ /bgm.html）。

## できること
- 再生・一時停止・スキップ・前の曲（途中なら頭から）・シーク。ロック画面の操作（Media Session。Android）
- 流す曲：すべて／お気に入り／プレイリスト。絞り込み：ジャンル・年代（5年ずつ：○○年代前半＝0〜4年・後半＝5〜9年）・曲の種類（OP/ED/挿入歌/その他）・知名度・アニメのタイトル（部分一致）。マイページの「もう聞きたくない」は外す
- 1曲の長さ：フル（イントロから最後まで）／TVサイズ（イントロから90秒）／サビだけ（サビの1秒前から45秒）。順番：シャッフル／新しい順／古い順
- ♡ お気に入り・＋ プレイリスト：マイページと同じ名前で保存（users.json の fav・playlists）。名前がなければ入れたときに聞く
- 🎤 歌詞：合言葉（歌詞クイズと同じ）を一度入れればその端末で見られる。時刻の合う歌詞（sync）→ 字幕 → 時刻のない歌詞 の順。時刻があれば今の行を光らせて送る
- 条件は端末に保存（localStorage aq-bgm）

## 見た目（ミュージックアプリの再生画面のような作り）
- 画面は3つ。下のアイコン（歌詞／選曲／次の曲）で切り替え、同じアイコンをもう一度押すとジャケットに戻る。どの画面でも再生は止めない
  - ジャケット：曲の動画を正方形に切り抜いて大きく出す。下に曲名・歌手（左寄せ）と ☆（お気に入り）・⋯（プレイリストに入れる・選曲）
  - 歌詞：上にジャケットと曲名を小さく、大きな太字の歌詞。いまの行だけはっきり、ほかは薄くぼかす
  - 次の曲：シャッフル／1曲リピート／長さ（フル→TVサイズ→サビだけ）／データ節約（自動→オン→オフ）のボタンと、前の10曲（薄く）・「再生を続ける（再生元）」次の20曲
- 共通の下側：太い再生位置のバー（触ったところへ。指で動かすあいだは太くなり時刻を出す。左は経過、右は残り時間）、大きな ⏮ ⏯ ⏭、音量（− ＋ のボタンで10ずつ・バーは触ったところへ・0 で消音。iPhone は YouTube が音量を変えさせないことがある）
- ⏮：曲の頭から3秒以上なら頭（0:00）へ、3秒未満なら前の曲へ
- 「サビへ」（再生位置のバーの下）：サビの1秒前へ
- ⋯ の「イントロ・サビの位置を直す」：−1／−0.1／+0.1／+1・今の位置・▶ 聴く で決めて送る（/api/fixes。収録曲一覧の「位置を直す」と同じで、イントロクイズでも使われる）
- 時刻のある歌詞は、行を押すとそこへ移る（TVサイズ・サビだけで流している範囲の外なら、その曲はフルにして流し直す）
- 背景はいまの曲の絵を大きくぼかして敷き、下ほど暗く。文字と操作は白
- 前後の曲のサムネイル（1枚3〜5KB、見えている分だけ読む）はデータ節約のときも出す

## 通信量（データ節約：自動／オン／オフ）
YouTube は音だけを流せないので、オンのときはジャケット（プレーヤー）を 230px までにして低い画質で送らせる（setPlaybackQuality tiny も呼ぶ）。
自動：Android はモバイル回線・データセーバーならオン、Wi-Fi ならオフ。回線を見分けられない端末（iPhone など）は、スマホならオン。

## 実装
- public/bgm.html・bgm.css・bgm.js
- server.js：POST /api/user/playlist（pl・id・on／del／rename。30個・1つ1000曲まで）、POST /api/bgm/lyrics（pass・id。合言葉は URL に入れない。1分30回まで）、userPublic に playlists
- 曲の一覧は /api/catalog（圧縮して送る）

## できないこと
- iPhone は画面を消すと止まる（YouTube の埋め込みの決まり）

## PiP用（試し）
選曲の窓の「画面を消しても聞きたい（PiP用）」をオンにすると、YouTube 自身のボタン（全画面など）を出す。iPhone の Safari は全画面から PiP にでき、PiP 中は画面を消しても鳴ることがある（YouTube が PiP を許さないこともある）。画面を消している間は、次の曲へ自動で進まないことがある。

## YouTube のプレイリストにする（2026-10-27 追加）
- 入口：選曲シートの「この条件で YouTube のプレイリストにする」、⋯メニューの「YouTubeのプレイリストにする」
- 元にする曲：今の条件／お気に入り／自分のプレイリスト（ログイン時）
- わけ方：ジャンルごと／アニメタイトルごと。並びはジャンル → アニメタイトル → 知名度 → 年
- 50曲ずつに分けて `https://www.youtube.com/watch_videos?video_ids=...` を開く（名前のない一時プレイリスト。YouTube側で保存可）
- 目的：Premium ならYouTubeアプリでロック中も流せる
