# アニソン・コードネーム（仕様書）

## 目的
2チームで、5×5の盤面から「自分のチームの作品」を先にすべて当てる遊び方（play `codenames`）。4人以上。盤面の1枚1枚は**作品（シリーズ）名**。当てたカードは、その作品の曲が流れる。

## 準備
- 参加者を赤・青の2チームに分ける（人数が奇数なら赤が1人多い）。各チームに**スパイマスター**が1人（回ごとに交代）。ほかは**探す人**。
- 盤面25枚の内訳：赤 9（先攻）／青 8／中立 7／暗殺 1（先攻のチームが9枚）。どれがどれかは、スパイマスターだけが見える。

## 1回（＝1ゲーム）の流れ
1. **ヒント（90秒）**：手番のチームのスパイマスターが、ヒントの言葉（12文字まで・盤面にある作品名そのものは不可）と数字（1〜9、0＝無制限）を出す。時間切れは「（なし）」・数字1。
2. **探す（90秒）**：そのチームの探す人が、カードをタップして当てる（チームの話し合いは、画面下の一言チャットで）。
   - 自分のチームの作品 → 続けて探せる（最大 数字＋1 枚）
   - 中立 → そこで手番交代
   - 相手チームの作品 → 相手の得点になって手番交代
   - **暗殺** → そのチームの負け
   - 「ここまで」で自分から手番を終えられる。
3. 先に自分の作品をすべて当てたチームの勝ち。

## 点数
- 勝ったチームの全員 +3000点（スパイマスターは +4000点）。
- 問題数＝回数（1回が1ゲーム）。

## 細かいきまり
- 盤面の作品は、すべて別のシリーズ。マイページの「もう聞きたくない」曲は使わない。
- めくったカードの曲は、全員に約8秒流れる。
- 再接続した人には、盤面とスパイマスターの正解表を送り直す。
- つながっていないスパイマスターは、手番が来たら自動で「（なし）」。

## 実装
- server.js：startCodenamesRound・cnStep・cnGuess・cnFinish、socket `cnClue`／`cnGuess`／`cnEnd`／`cnChat`。盤面は `cnPhase`（全員）、正解表は `cnKey`（スパイマスターだけ）。
- 画面：専用の窓（#cnPop）。1画面に収める（盤面は画面の高さに合わせる）。
