# アニソン大富豪（仕様書）

## 目的
曲のカードで大富豪。**カードの強さは曲の発売年（新しいほど強い）**。ただし手札の年は見えない（曲名・作品名・歌手だけ）。年の知識で、場より新しい曲を出していく遊び方（play `daifugo`）。3人以上。

## 1回（＝1ゲーム）の流れ
1. 1人7枚ずつ配る（全部ちがう年の曲）。最初の親はランダム。
2. 親は好きな1枚を出す（出した曲は年が見える）。
3. 順番に、**場の曲より新しい年の曲**を1枚出すか、パス（25秒。時間切れはパス。親の時間切れはランダムに1枚出す）。
   - 出した曲が場より新しくなければ**失敗**：カードは手札に戻り、−200点、パス扱い。
4. 出した人以外が全員パスしたら場が流れ、最後に出した人が親になる。
5. 手札がなくなった順に上がり。残り1人になったら終わり。

## 点数
- 1位（大富豪）+3000／2位（富豪）+2000／3位 +1000、最後の人（大貧民）0。失敗は1回 −200点。

## 細かいきまり
- 自分の手札の曲は試聴できる（「聴く」）。
- つながっていない人は自動でパス（親ならランダムに1枚）。
- 上がった人の次が親になるべきときは、その次の人が親。
- 1画面に収める。

## 実装
- server.js：startDaifugoRound・dfNext・dfPlay・dfPass・dfFinish、socket `dfPlay`／`dfPass`／`dfPreview`。手札は `dfHand`（本人だけ）、場は `dfPhase`（全員）。
- 画面：専用の窓（#dfPop）。
