# アニソン・デッキ構築（ドミニオン風・仕様書）

## 目的
いつものイントロクイズで**コイン**を稼ぎ、3問ごとのショップでカードを買って自分の「デッキ（持ち札）」を育てる（play `deck`）。コインを増やす仕組みに投資するか、早めに点数に換えるかの駆け引き。1人からでも遊べる。

## コイン
- 正解すると：いちばん速い人 +3、ほかの正解 +2。
- 「💰投資」を持っていると、正解のたびに 1枚につき +1。

## ショップ（3問ごと・20秒）
| カード | 値段 | 効果 |
|---|---|---|
| ✂ 50:50 | 2 | 問題中に使う：不正解の選択肢を半分消す（入力のときは文字数と最初の文字） |
| 👥 オーディエンス | 2 | 問題中に使う：ほかの人がどれを選んだか見える |
| 🔁 もう一度聴く | 1 | 問題中に使う：イントロをもう一度聴く |
| ✖2 ブースト | 3 | 自動：次に正解したとき、その問題の点数が2倍 |
| 💰 投資 | 4 | ずっと：正解のたびにコイン +1 |
| 👑 勝利点 | 5（買うたびに +1） | すぐに +1000点 |

- 何枚でも買える（コインが足りる分）。全員「終わる」を押すか、時間で次の問題へ。
- 使い切りのカード（50:50・オーディエンス・もう一度聴く・ブースト）は、使うとなくなる。

## 画面
- 左のプレイヤー一覧の下に、自分のコイン・持っているカード（問題中は「使う」ボタン）を小さく出す。
- ショップは1画面の窓（6枚のカードを3列×2段）。

## 実装
- server.js：player.dk（coins・invest・boost・vpBought）、dkReveal（答え合わせでコイン・ブースト）、startDkShop／finishDkShop（nextQuestion で3問ごと）、socket `dkBuy`／`dkDone`。問題中に使うカードは、既存のライフライン（`lifeline`／useLifeline）を使う。
- public/app.js：renderDeck（#dkBox）、ショップ窓（#dkPop）。
