# アニソン伝達クイズ（play: 'dentatsu'）

## 目的
1人だけが曲を聴き、文字のヒントでほかの人に伝えるパーティー向けの遊び方。

## 流れ（1問ごと）
1. 伝える人を決める（順番に全員。一巡ごとに順番をまぜる。抜けた人は飛ばす）
2. 伝える人だけにイントロが流れる。「▶ イントロ」「▶ サビ」で何度でも聴き直せる（20秒ずつ）。伝える人には曲名・作品名・歌手名も見える
3. 伝える人は文字のヒントを送る（1つ30文字まで・10個まで）。曲名・作品名・歌手名（2文字以上の名前・別名）を含むヒントは送れない
4. ほかの人は、ヒントが1つ以上出たら選択肢から1回だけ選ぶ。選択肢は伝える人には見えない
5. 全員が選ぶか、100秒たったら答え合わせ。みんなでサビを聴く

## 点数
- 答える人：正解で100点＋早いほど最大50点（最初のヒントから時間切れまでの残り時間の割合）
- 伝える人：正解した人1人につき100点
- 最終問題2倍の設定は両方に効く

## 設定
- 選択肢の数（dtChoices）：4／8／12（既定8）
- 2人以上。チーム戦はなし
