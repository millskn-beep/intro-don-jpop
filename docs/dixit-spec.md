# アニソン・ディクシット（仕様書）

## 目的
語り手が曲に一言ヒントを付け、ほかの人は手札の曲から「ヒントに合う曲」を出し、出た曲の中から語り手の曲を当てる遊び方（play `dixit`）。3人以上。ボードゲーム「ディクシット」の曲版。

## 1回の流れ（問題数＝回数。語り手は順番に交代）
1. **語り手（60秒）**：手札の5曲から1曲を選び、ヒントを一言（20文字まで）。曲は「聴く」ボタンでサビあたりを試聴できる。時間切れなら、ランダムな1曲・ヒント「（なし）」。
2. **出す（45秒）**：語り手以外が、ヒントに合うと思う曲を手札から1曲出す（試聴できる）。時間切れはランダム。
3. **投票（60秒）**：語り手の曲と、みんなが出した曲をまぜて表示（曲名・作品名。試聴できる）。語り手以外が、語り手の曲だと思うものに投票（自分の曲には入れられない）。
4. **結果**：語り手の曲・だれがどれを出したか・票を見せる。

## 点数（1点＝500点）
- 全員が当てた、または全員が外した → 語り手 0点、ほかの人 +2点
- それ以外 → 語り手 +3点、当てた人 +3点
- 自分の出した曲に票が入ると、1票につき +1点（最大3点）

## 細かいきまり
- 手札は5曲。毎回5曲にそろえる。同じ曲名・同じ作品は同じ手札に入れない。マイページの「もう聞きたくない」曲は配らない。
- 抜けた人は待たない（つながっている人だけそろえば次へ進む）。
- 再接続した人には、いまの段階と自分の手札を送り直す。
- チーム戦はなし。点数の多い順が順位。

## 実装
- server.js：startDixitRound（nextQuestion から）・dixitStep・dixitFinish、socket `dxTell`／`dxPick`／`dxVote`／`dxPreview`。手札は `dixitHand`（本人だけ）、場は `dixitPhase`（全員）。
- 試聴は人狼と同じ `wolfSong` の仕組みを使う。
- 画面：専用の窓（#dixitPop）。
