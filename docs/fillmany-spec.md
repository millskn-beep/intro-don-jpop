# たくさん埋めバトル（play: fillmany）

3つ埋めバトル（fill）の枠を 4〜8 個に増やした遊び方。進め方・点数・お手つきは 3つ埋めバトルと同じ。

- 枠の数：設定「枠の数」（fillN：4〜8、初めは 6）
- 最初の3つ：曲名・アニメ名・アーティスト（ボカロは曲名・作者・VOCALOID）。書くか10択
- 4つ目から：下の枠から曲ごとにランダム（作れない枠は飛ばす）。どれも選択式だけ（点数は半分）
  - 発表年（前後6年から10択、年の順）
  - 使われ方（OP・ED・挿入歌・主題歌・映画主題歌・イメージソング・キャラソン・劇中歌）
  - ジャンル（その曲のジャンルの1つ。LoL・パチスロ・ボカロ・J-POP・その他・映画は使わない）
  - 同じアニメの別の曲（同じシリーズの別の曲が1つ正解。ボカロでは出ない）
  - 同じ歌手の別の曲（ボカロは「同じ作者の別の曲」。名義に同じ人が入っている曲は外れの選択肢にしない）
  - 再生回数（100万回未満／〜1000万／〜5000万／〜1億／1億回以上の5択）
- 1曲で全部埋めた人：称号「総取り」
- 実装：server.js の fillExtras・buildFill（isFillPlay）、public/app.js の isFillPlay
