# アニソン・ジャンル制覇（トリビアル・パスート風・仕様書）

## 目的
いつものイントロクイズで、6つのジャンルの「ピース」を集める。先に6つ全部そろえた人の勝ち（play `genre`）。1人からでも遊べる（2人以上がおすすめ）。

## ジャンル（6つ）
🔥 ジャンプ／🤖 ロボット・SF／💕 ラブコメ・日常／🎤 アイドル・バンド／🗡️ 異世界・ファンタジー／🎮 ゲーム・スポーツ

## 流れ
1. 毎問、どれか1つのジャンルの曲が出る（画面にジャンルを出す）。最初のジャンルはランダム。
2. 答え合わせで、**いちばん速く正解した人**が、そのジャンルのピースをもらう（もう持っていれば +300点）。
3. 次の問題のジャンルは、設定で選べる：**選択制**（最速の正解者が選ぶ）／**ランダム制**（毎問ランダム）。選択制では、その人が**次の問題のジャンルを選ぶ**（10秒。時間切れは、その人がまだ持っていないジャンルからランダム）。自分の足りないジャンルを選ぶか、相手が欲しいジャンルをつぶすかの駆け引き。
4. だれも正解しなかったら、次のジャンルはランダム。
5. 6つそろえた人が出たら、その問題で終わり（そろえた人 +3000点）。最大60問。順位はピースの多い順（同じなら得点）。

## 画面
- 左のプレイヤー一覧の下に、いまのジャンルと全員のピース（6マス）を小さく出す。
- ジャンルを選ぶ人には、6つのボタンの小さな窓を出す（1画面に収める）。

## 実装
- server.js：GZ_CATS、game.gz（pieces・cur・pick）、gzReveal（答え合わせ）、gzChoose（socket `gzChoose`）、nextQuestion で次の曲をそのジャンルから選ぶ。
- public/app.js：renderGenreZone（#gzBox・#gzPop）。

## 集めるジャンルの決め方（設定「集めるジャンル」）
- **固定（今の6つ）**：ジャンプ／ロボット・SF／ラブコメ・日常／アイドル・バンド／異世界・ファンタジー／ゲーム・スポーツ。
- **ランダム**：ゲームごとに、ジャンル（約20種類）からランダムに6つ。
- **選択**：「集める種類を選ぶ」の画面で、ジャンルを最大6つ（2つ以上）選ぶ。部屋のだれでも決められる。
- 「次のジャンル」の決め方（選択制／ランダム制）は、問題ごとの話で、これとは別。

# アニソン・ジャンル制覇EX（play `genreex`）
ジャンル制覇の発展版。集める「種類」を6つより多くできる。
- **種類のカタログ（約37種類）**：ジャンル（ジャンプ・ゲーム原作・ギャルゲー・ジブリ・劇場オリジナル・映画・スポーツ・異世界・ラブコメ・日常系・アイドル・ロボット・SF・キッズ・パチスロ・ボカロ・J-POP・アクション・ホラー・魔法少女・ドラマ）／年代（〜1989・90年代・00年代・10年代・20年代）／曲の種類（OP・ED・挿入歌・映画主題歌・ボカロ・キャラソン）／知名度（超有名〜オタク）。曲が8曲に満たない種類は出さない。
- **ランダム**：カタログから 6〜25 種類（設定で数を選ぶ）をゲームごとにランダムに決める。
- **選択**：好きな種類を何個でも（2つ以上）選ぶ。
- 流れ・点数は同じ。毎問、集める種類のどれか1つの曲が出て、最速の正解者がその種類のピースをもらい、**選んだ種類を全部そろえた人**の勝ち（+3000点）。
- 画面：左の欄はピースが折り返して並ぶ。種類を選ぶ画面は、グループ（ジャンル・年代・曲の種類・知名度）ごとに並ぶ。
