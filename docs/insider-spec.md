# アニソンインサイダー（仕様書）

## 目的
出題者だけが答え（曲）を知っていて、みんなが「はい／いいえ」で答えられる質問をして当てる。ただし、みんなの中に答えを知っている人（インサイダー）が1人まぎれている。当てたあと、だれがインサイダーかを投票で見つける遊び方（play `insider`）。3人以上（4人以上がおすすめ）。

## 設定
- 曲の聞かせ方（insHear）：`master`＝出題者とインサイダーだけが曲を聴ける（ほかの人は聴けない）／`intro`＝全員にイントロだけ流す（出題者とインサイダーは答えも知っている）
- 当てるもの（insTarget）：`song` 曲名／`work` 作品名
- チーム戦はなし

## 1回の流れ（問題数＝回数）
1. **役（10秒）**：出題者は順番に交代、インサイダーは出題者以外からランダム。自分の役だけが見える（出題者も、インサイダーがだれかは知らない）。出題者とインサイダーには答え（曲名・作品・歌手）が見え、曲を聴ける（「聴く」ボタンで何度でも）。intro のときは全員にイントロが流れる。
2. **質問（150秒）**：出題者以外がチャットで質問（60文字まで）。出題者は質問ごとに「はい／いいえ／わからない」を押して答える。答えが分かったら、答えの欄に入れて出す（入力候補あり。惜しいときは打ち直し）。だれかが正解したら次へ。時間切れなら全員の負け（点数なし）。
3. **話し合い（60秒）**：だれが当てたかを見ながら、インサイダーがだれかを話す。全員が「投票へ進む」を押すか、時間で次へ。
4. **投票（30秒）**：インサイダーだと思う人に投票（自分以外。出題者も投票する）。
5. **結果**：いちばん票の多い人が1人だけで、それがインサイダーなら、出題者とみんなの勝ち（+1000点）。同票・外れならインサイダーの勝ち（+2000点）。答えた人にはさらに +300点。役・答え・票を見せ、サビを流す。

## 細かいきまり
- 役と答えは、その人の端末にだけ送る（部屋全体には送らない）。再接続したら送り直す。
- 抜けた人は待たない。
- 曲名当てでは作品名を言っても正解にしない（当てるものに合わせて判定）。

## 実装
- server.js：startInsiderRound・insStep・insTally・insFinish、socket `insAsk`／`insReply`／`insGuess`／`insReady`／`insVote`／`insListen`。
- 画面：#insPop（人狼と同じ .wf-* の窓）。曲は `wolfSong` で流す。
