# アニソン帰れま10（仕様書）

## 目的
テレビの「帰れま10」のアニソン版。お題（歌手・シリーズ・年）の曲の中から、**再生回数トップ10**の曲を全部当てたら「帰れる」（play `kaerema`）。みんなで協力しつつ、当てた人に点数。1人からでも遊べる。

## 1回（＝1つのお題）の流れ
1. お題を出す：例「LiSA の曲 再生回数トップ10」「ガンダムシリーズの曲 トップ10」「2015年のアニソン トップ10」。
2. 候補の曲（20曲：トップ10＋それ以外10曲）を一覧で見せる（順位は見えない）。
3. 順番に1人ずつ、トップ10に入っていると思う曲を1曲選ぶ（30秒。時間切れはとばす）。選んだ曲のサビが全員に約8秒流れ、順位を公開。
   - トップ10なら当たり（盤の順位の場所に入る）。
   - トップ10でなければ外れ（「13位」のように順位を出す）。外れは6回まで。
4. トップ10を全部当てたら「帰れる！」。外れが6回になったら「帰れません…」で終わり（残りの順位を公開）。

## 点数
- 当たり：+500点、1位を当てたら +1000点。
- 10曲目を当てた人：+2000点。帰れたら全員 +1000点。
- 外れ：0点。

## お題の選び方
- 曲が14曲以上ある歌手・シリーズ・年から、ランダムに選ぶ（部屋の年代やジャンルの設定に合う曲を優先）。
- 同じ曲名（版ちがい）は1つにまとめる（再生回数の多いほう）。
- 再生回数は、このアプリが持っている YouTube の再生回数。

## 画面（1画面に収める）
- 左：トップ10の盤（1〜10位の枠。当たると曲名と当てた人が入る）。
- 右：候補20曲（4列×5段）。選んだ曲は当たり・外れと順位の印。
- 上：お題・あと何曲・外れの残り・いまの番の人。

## 実装
- server.js：startKaeremaRound・kmTurn・kmPick・kmFinish、socket `kmPick`。場は `kmPhase`（全員）。

## お題の種類（追加）
歌手／作品・シリーズ／年に加えて、**ジャンル**（スポーツ・ロボット・魔法少女…）、**年代**（90年代のアニソン）、**曲の種類**（OP・ED・挿入歌・映画主題歌）、**組み合わせ**（2010年代のOP・90年代のロボットの曲・2015年のOP など）。お題の種類を先にランダムに選んでから、その中からお題を選ぶので、種類がかたよらない。J-POP・ボカロ・パチスロ・LoL のお題は、お題で指定したときだけ。
