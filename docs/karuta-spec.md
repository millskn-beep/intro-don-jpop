# アニソンかるた（仕様書）

## 目的
並べた札から、流れた曲の札を早取りする遊び方（play `karuta`）。選択肢を読むより「場を覚えて探す」楽しさ。

## 遊び方
- 画面に16枚（4×4）の札を並べる。札に書くものは部屋の設定「札に書くもの」で選ぶ：曲名（既定）／作品名（シリーズ名）／歌手名。
- 札は場に置いたまま（位置は変わらない）。流れる曲の札は必ず場にある。
- イントロが流れたら、正しい札をいちばん早く取った人がその札をもらい、その場で答え合わせ。
- 違う札を取るとお手つき：その曲はもう取れず、次の1曲はお休み（画面に「お休み」）。
- だれも取れなければ（全員パス・お手つき・時間切れ）、答え合わせで、その曲の札は取った人なしで場から消える（その曲はもう流れないので）。
- 取られた札は場から消え、空いたところに次の札が入る（これから流れる曲の札 → なければ流れない札）。同じ文字の札は2枚置かない。
- 問題数まで。取った札の多い順、同じなら得点の順。

## 細かいきまり
- 入力で答える設定でも、かるたは札を取る（選択肢）だけ。
- ヒント：札が作品名なら「作品の頭文字」、歌手名なら「歌手」のヒントは出さない。
- マイページの苦手な曲：札に触らなかった曲（ほかの人に取られただけ）は苦手にしない。お手つき・パスは苦手に入る。
- チーム戦はなし。

## 実装
- server.js：karutaChoices（場の16枚を選択肢として出す。g.karuta）・karutaTake（答え合わせで札を取る）・お手つきの p.karutaRest・最初の正解で答え合わせ。
- 画面：選択肢の欄を4×4の札の見た目にする（.choices.karuta）。プレイヤー欄に取った札の数（🎴）とお休み。
