# アニソンモノポリー（仕様書）

## 目的
モノポリーの盤面でイントロクイズを遊ぶ（play `monopoly`）。土地を買って家賃を集め、15問（約15分）のあと「持ち点＋土地」の合計で順位を決める。1人から遊べる（3人以上がおすすめ）。すごろくとは別のモードで、画面も専用。

## 画面
- ふだんは盤面を全画面で出す。クイズと答え合わせのあいだだけ、今のクイズ画面に切り替える。
- 盤は 本物と同じ 40マス（11×11の外周）。マスに国の色・土地の名前・持ち主・必要カード枚数・アイコンを出す。マスを押すと権利書（家賃の表）を出す。
- 真ん中に、全員の状況、いまの出来事、自分にできること（購入・取引所など）を出す。
- コマは名前の札で、1マスずつはねて進む。到着したマスはその人の色で光り、名前を出す。全員の現在地は金庫の欄にも出す。

## 国と都市
- 設定 `mpBy`：ジャンル／作品／歌手／まぜる／自分で選ぶ（ジャンル制覇と同じ選び方。最大8つ）。中身はランダム。
- 8か国・22都市（最初と最後の国は2都市、ほかは3都市）。都市は、国がジャンルや歌手なら作品、作品なら曲名。自分のカードは国の色で並べて見せる。
- 公共交通4路線（買値500点。家賃は持っている数で300／600／1200／2400点）と、公共施設2つ（買値400点。家賃はサイコロの目×60、2つ持ちで×180）。
- 問題の曲は、その回の国の曲から出す。

## 1ターン
1. 全員が同時にサイコロ2個を振る。その回の国を決める。
2. イントロクイズ。
3. 答え合わせを少し見せてから、盤面に戻る。正解の速い順、続いて不正解の人の順にコマが進む。
4. 行動タイム（5〜10秒。全員が「OK」を押せばすぐ次へ）。

## 正解の特権
| 条件 | もらえるもの |
|---|---|
| 正解 | その回の国のカード1枚 |
| 最速の正解 | さらに +100点。先に動くので土地を先に取れる。刑務所からすぐ出られる |
| 5秒以内の正解（早耳） | サイコロを振り直し、合計の大きいほうで進む |
| 不正解・パス | カードと点はなし。コマは進む |
| 最下位の人 | 正解に関係なく、ランダムな国のカード1枚（全員同点なら配らない） |

クイズの通常の点数は使わず、上の点に置きかえる。始めの持ち点は 1500点。

## マス
- **都市（空き地）**：ポイント +100 か国のカード1枚（ランダム）。最初に止まった人は買える。
  - 値段：高い国ほどカードが多い（1〜5枚）。足りない分は1枚 250点で払える。
- **都市（自分の土地）**：同じ報酬。行動タイムにカードを払えば家を建てられる（どの土地でも最大4軒、1ターン1軒）。
- **都市（他人の土地）**：家賃を払う。家賃は国ごとに上がり（120〜1320点）、家で最大11倍。同じ国を全部持つと家なしの家賃は2倍。持ち点が足りなければ、ある分だけ払う。
- **スタート**：通過で +200点。各周で最初に一周した人は、さらに +300点と、次の問題の国を選ぶ権利。
- **取引所**：止まった人は、そのターンのカード購入が半額。
- **税金**（円盤代200点・遠征費100点）。**グッズ箱**（3マス）：点の増減やカード。
- **刑務所へ**：刑務所に移り、次のターンは進めない（最速で正解すれば出られる）。刑務所のマスに止まるだけなら何もない。
- **チャンス**（4マス）：点が増減する、カードをもらう、全員から点をもらう、スタートへ進む、刑務所へ行く、次の国を選ぶ。

## 取引所（行動タイムならいつでも）
- カードを買う 250点、売る 125点。
- トレード：相手を選び、カードまたは点と、相手のカードの交換を申し込む。相手が受ければ成立。

## 演出
点の増減は大きな数字、カードは国の色のカード、土地の取得と家は紙吹雪と大きな帯、家賃はコインが相手へ飛ぶ。

## 終わり
15問で終わり、持ち点＋土地の値段（家を含む）で順位を決める。余ったカードは0点。土地の評価は部屋の設定で買値の全額か半額を選ぶ（`mpLand`）。

## チーム戦（赤・青。部屋のチーム戦の設定で）
- コマ、サイコロ、解答、持ち点は個人のまま。土地とカードはチームで共有する。
- 味方の土地は家賃なし。味方の土地に止まると、自分の土地と同じ報酬をもらう。味方どうしのトレードはできない。
- 買う人の持ち点で払い、共有カードから使う。家を建てるのも共有カード。
- 家賃は接続中の味方で等分（10点単位。端数は買った人）。
- 最下位の救済カードは、合計の少ないチームに1枚（同点なら配らない）。
- チャンスとグッズ箱の「全員から」「全員に」は相手チームだけが対象。
- 勝敗はチームの持ち点の合計＋土地。個人の順位は、持ち点＋土地を人数で割った額。人数が違うと多いチームが有利になる。

## ルールの根拠（2026-11-01 の試算。正解率80/60/40/25%の4人・500試合）
- 見直し前（正解で点＋カード、最速カード2枚、余りカードにも点）：勝率 96/4/0/0%。家賃は順位にほとんど効かなかった。
- 今のルール：勝率およそ 53/27/10/10%（土地を半額に数える設定なら 54/21/12/13%）。上手な人が有利で、残りの人にも勝ち目がある。家賃は1試合約10回・平均約450点。
- 同じ国の独占は15問では1試合0.1回前後で、ほとんど起きない。

## 実装
- monopoly.js（サーバー）：盤づくり、ターン、移動、行動。server.js からは nextQuestion・答え合わせ・publicRoom・順位で呼ぶ。
- public/monopoly.js・public/monopoly.css：盤面の画面。
