# マイページ（仕様書）

## 目的
名前だけで登録して、お気に入り・苦手な曲・もう聞きたくない曲・成績・称号を、端末をまたいで残す。

## ログイン
- `/me.html` で名前（2〜12文字）を入れると、初めての名前なら登録、使ったことのある名前ならログイン。合言葉はない。
- 名前の比べ方：NFKC・前後の空白なし・小文字（全角Ａと半角Aは同じ人）。同じ名前は1人だけ。
- 名前を知っていればだれでも開けるので、画面で「人と被らない名前に」と案内する。
- ブラウザは `localStorage['aq-user']` で覚える。部屋に入る（create/join）ときに名前を送り、登録済みなら席に結びつける（socket `login` でも結びつく）。

## リスト（それぞれ別の枠）
| 枠 | 入れ方 | 出題への効き方 |
|---|---|---|
| ♡ お気に入り（fav） | 答え合わせ画面・収録曲一覧の ♡ | お題「お気に入り」で出題（部屋にいる人の分を合わせる）。ほかのお題では、ふつうの曲と同じ扱い（前に出た曲・最近出た曲の除外も同じ。2026-11-01 に変更） |
| 🚫 もう聞きたくない（block） | 答え合わせ画面・収録曲一覧の 🚫 | その人が部屋にいる間は、どのお題でも出題しない（部屋の除外とは別） |
| 🎯 苦手な曲（weak＋again） | 間違えた・パスした曲を自動で（回数）／答え合わせ画面の「🎯 もう一度出して」 | お題「苦手な曲」で出題。正解すると外れる |

- お気に入りともう聞きたくないは逆：片方に入れるともう片方から外れる。
- お題「お気に入り」「苦手な曲」は、年代・知名度の設定に関係なく全部が候補。

## 成績・称号
- ゲームの終わりに：遊んだ回数、1位の回数（2人以上のときだけ）、遊び方ごとの回数、もらった称号（種類ごとの回数）。
- 答え合わせごとに：答えた数・正解数。

## 保存
- サーバーのメモリと `data/users.json`（gitignore。手元の動作確認用）。
- 本番は GitHub の data-log ブランチ（`datalog/state.json` の `users`）に記録し、起動時に必ず読み直す（版が変わっても。リクエストなどと違い手元には取り込まない）。起動は読み直しを待ってから受け付ける（最大8秒）。
