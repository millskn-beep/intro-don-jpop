# アニソン年表（仕様書）

## 目的
ヒットスターのように、流れた曲が「何年の曲か」を自分の年表の正しい位置に置く遊び方（play `nenpyo`）。曲名がわからなくても時代の感覚で戦える。

## 遊び方
- 始めに一人ひとり、年の見えている曲を1枚もらう（出題に使わない曲から。マイページの「もう聞きたくない」曲は除く）。
- 曲が流れる（年は伏せる。ヒントの「年」も出さない）。自分の年表の「この曲とこの曲の間」（いちばん前・いちばん後ろも）を1つ選ぶ。
- 答え合わせで年が出る。合っていれば（前の曲の年 ≤ この曲の年 ≤ 後ろの曲の年。同じ年はどちらでも正解）その曲が年表に入る。外れたら入らない。
- 全員同時に置く（待ち時間なし）。点数はふつうと同じく速いほど高い（合っていたときだけ）。
- だれかの年表が10枚になったら、その問題で終わり（問題は最大60問）。年表の枚数の多い順、同じなら得点の順。
- 曲名を当てるボーナスはなし（位置だけ）。
- 年表はほかの人からも見える（プレイヤー欄に枚数📅）。答え合わせの前に年がばれないよう、カードは答え合わせのときに入れる。

## 実装
- 判定：lib/nenpyo.js（fits・insert）。
- server.js：nenpyoStartCard（始め）・onAnswer の slot（answer { slot }）・nenpyoReveal（答え合わせで年表に入れる・10枚で g.nenpyoDone）・終わりの順位。
- 画面：選択肢の代わりに、自分の年表と「▼ここ」のボタン（#nenpyoBox）。
- チーム戦はなし。最終問題2倍は、早く終わると働かないことがある。
