# アニソン陣取り（仕様書）

## 目的
アタック25のように、5×5のパネルをクイズの正解で取り合う遊び方（play `panel`）。終盤の逆転を楽しむ。

## 遊び方
- 出題・答え方はふつうと同じ（全員で答える）。
- 答え合わせで、いちばん早く正解した人がパネルを1枚選ぶ（15秒。時間切れは、いちばん多く裏返せるマスを自動で選ぶ）。
- 選べるマス（本家どおり）：
  - 最初の1枚は真ん中（13番）。
  - そのあとは、取られているマスの隣（縦横斜め）の空きマス。そのうち挟んで裏返せるマスがあれば、そこからしか選べない。
- 置いたマスと自分の色で縦・横・斜めに挟んだ相手のマスが、自分の色に変わる（オセロと同じ）。
- 正解者がいない問題は、だれも選ばない。
- 25マスが埋まったら終わり（問題は最大60問）。パネルの多い順、同じなら得点の順。

## 画面
- 問題中：選択肢の下に小さい盤と、各自の色・枚数。
- 選ぶとき：大きな盤を画面の上に出す。選ぶ人だけ、選べるマス（点線）を押せる。ほかの人は見ているだけ。
- 取ったあと：置いたマスが光り、裏返ったマスがめくれる演出（3枚以上はカットイン）。2.5秒見せてから次へ。

## 実装
- 盤の判定：lib/panel.js（flipsOf・allowedCells・place・autoPick）。
- server.js：startPanelPick（答え合わせのあと）・panelChoose（socket `panelChoose`）・選んでいる間は nextQuestion を止める・終わりの順位。
- チーム戦はなし。最終問題2倍は、盤が埋まって早く終わると働かないことがある。
