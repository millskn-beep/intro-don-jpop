# プレイリストの未収録曲をオンラインで遊べるようにする（仕様書・案）

## 目的
プレイリストにあって、まだ収録されていない曲（約570曲）を、オンラインのゲームで遊べるようにする。
遊びながら良い曲だけを、本採用の曲データに入れていけるようにする。

## 考え方（あなたの答えの読み取り）
- 「1＋3」＝ YouTube が見つかった曲を全部「お試し」で曲データに入れ、専用のお題で遊べるようにする。そのうち有名度が「普通」以上の公式動画の曲は、最初から本採用にする。
- 「サビの画面で大きく『これはゲームデータに入れる』」＝ ゲーム中、答えが出てサビが流れる画面に、お試しの曲だけ大きなボタンを出す。実際に聴いて確かめてから本採用にする。
- 「常にイントロ/サビを入れる」＝ お試しの曲も、イントロ・サビの秒数が必ず入る状態にする（自動で測る。測れなければ長さからの推定を入れる）。

## 作るもの
1. **取り込み（tools/stage-preview.js）**：プレビューの一覧から、YouTube があり（カバー等・収録済みでない）ノイズでない曲を `songs.json` に「お試し（staged）」として入れる。作品名はアルバム名の『…』から取り、種類（OP・ED）も読み取る。再生回数（あなたの再生回数）は入れない。
2. **測定**：入れた曲を、いつもの測定（イントロ・サビ・再生回数・知名度・動画の確認）にかける。時間がかかるので裏で走らせる。
3. **お題**：「プレイリスト（お試し）」を追加。お試しの曲は、ふだんのお題・選択肢には出さない。このお題を選んだときだけ、お試しの曲だけで出題する（選択肢もお試しの曲から）。
4. **ボタン**：答え合わせ画面（サビ）に「これはゲームデータに入れる」を大きく出す（お試しの曲だけ）。押すと記録される。
5. **取り込み側**：反映の前にいつもの手順に `tools/pull-promotes.js` を足し、本番で押された曲を本採用に切り替える。
6. **プレビュー画面**：お試しの曲に「お試し中（オンラインで遊べる）」を出す。「追加」を押すと本採用に切り替わる。

## 手順
1. 取り込み → 2. 測定（裏で）→ 3. サーバー・画面 → 4. 3001番で遊んで確認 → 5. 「反映して」を待つ。

## 気をつけること
- 測定中は曲データを書き換えるので、その間はプレビュー画面で追加しない。
- 作品名が取れない曲は「その他」。お題「プレイリスト」では「作品」を答えるお題が出にくい。
- 反映するまで本番には出ない。
