# アニソン・ポーカー（仕様書）

## 目的
アニソンクイズで集めた「曲のカード」（トランプ）で、ポーカーの役を作って競う遊び方（play モード `poker`）。

## 遊び方
- 全員が同じ曲を聴いて答える（ふだんのクイズと同じ）。
- 正解した人は、その曲のカードを1枚引く。いちばん早く正解した人は、ランダムのカードをもう1枚引く（ジョーカーなし）。
- 手札は5枚。超えたら自分で捨てる（選ばなければ、次の問題の前に強い5枚が自動で残る）。
- カードの中身は自分の画面だけ。他の人には枚数だけ見える。カードに触れると曲名・作品・歌手などが出る。

## カード
- 数字（A〜K）＝作品。ゲームの中で作品ごとに13種を割り当てる（同じ数字＝同じ作品）。
- マーク＝ジャンル系統（♠バトル・ロボット・SF／♥恋愛・日常・アイドル／♦異世界・ゲーム・劇場・キッズ／♣その他）。部屋設定「マークの決め方」でランダムにもできる。
- 知名度が低い曲ほど、銀・金の箔のカードになる。

## 役（強い順）
ファイブカード／ロイヤルストレートフラッシュ／ストレートフラッシュ／フォーカード／フルハウス／フラッシュ／ストレート／スリーカード／ツーペア／ワンペア／ハイカード。
同じ役どうしは、レアな（知名度の低い）カードを使っている方が強い。

## 10問ごとの中間オープン（賭け）
- 持ち点の 0 / 25% / 50% / 全部 を賭ける（25秒）。
- 賭けた人が2人以上なら、役の強い人が賭け金を総取り（同点は山分け）。1人以下なら勝負なし。
- オープンした手札は「保管」に回り、最後に1枚 +50点。

## 特殊演出
答え合わせのあと、40%の確率で1つ発生：カードドロー／カード1枚入れ替え／全入れ替え（低め）／2枚渡し（2人で交換。3人以上は相手をランダムに1人）。

## 最後（ショーダウン）
ポーカー場のテーブルで、最下位から順に手札をめくる。役ボーナス（役のランク×100点）と保管ボーナスを点に足し、点の多い順が順位。

## 調整する値（server.js の POKER_* 定数）
賭けの間隔・秒数、特殊演出の確率、保管・役のボーナス点。
