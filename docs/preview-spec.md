# 曲の追加プレビュー画面（仕様書・案）

## 目的
自分の曲の一覧（アニソンdrive.txt）の中で、まだカタログにない曲を洗い出し、YouTube にあるか・どれくらい有名かを見比べて、気に入った曲をその場で追加できるようにする。
今後の追加候補（「追加を検討中」の曲など）も、同じ画面から追加できるようにする。

## 作るもの
1. **一覧づくり（裏の処理）**
   - アニソンdrive.txt（Apple Music の書き出し。579曲）を読み、カタログにある曲を除く。
     - 曲名で一致しても、歌手がちがう曲（同じ曲名の別の曲）は「入っていない」側に入れる。
   - 入っていない曲ごとに、YouTube を検索して、上位の動画（チャンネル・再生回数・公式かどうか）を5つまで保存する。
2. **プレビュー画面**（このPCからだけ開ける。収録曲一覧の「確認画面」と同じ作り）
   - 1行ごとに：曲名・歌手・アルバム（作品）・年・長さ、あなたの再生回数、YouTube の候補（▶で試し聴き）、有名度の目安。
   - 動画を選び、曲名・歌手・作品・年・種類を直して、「追加」か「見送り」を押す。
   - 絞り込み：未追加／追加済み／見送り／検討中（投票あり）。並べ替え：再生回数・あなたの再生回数。
3. **追加したあと**
   - 「追加」を押すと、曲データに入る（イントロ・サビ・再生回数は「未測定」）。
   - 「測定を実行」ボタンで、まとめて測る（イントロ・サビ・再生回数・動画の長さ・読みがな・ジャンルのタグ・パチスロの確認）。
4. **今後の候補**
   - 「追加を検討中」の曲（投票つき）も同じ画面に出す。ここで追加すると、検討中から外れる。
   - 画面から曲名・歌手を入れて候補を足すこともできる（YouTube を検索して候補を出す）。

## 手順
1. （いま裏で実行中）入っていない曲＋曲名だけ同じ曲を YouTube で検索して保存する。
2. サーバーに、画面用の入り口（一覧・追加・見送り・測定）を足す。このPCからだけ使える。
3. 画面（preview.html）を作る。
4. 3001番で、追加→測定→ゲームで出る、までを確かめる。

## 保存するもの
- `data/preview.json`：候補・状態（未追加／追加済み／見送り）。**あなたの再生回数が入っているので、gitには入れない**（公開しない）。
- 追加した曲は `data/catalog/additions-preview.csv` に書き、いつもの取り込み（import-catalog）で曲データに入れる。

## 気をつけること
- アルバム名が曲名と同じシングルが多く、**作品名が空の曲がほとんど**。追加の前に、作品名を入れてもらう（空のままなら「その他」）。
- CM曲（23秒など）・リミックス・コンピレーションの曲は、初めは隠して、「全部見る」で出せるようにする。
- 有名度は、YouTube の上位の動画の再生回数と、公式のチャンネルかどうかを出す。段階（超有名〜オタク）は、いつもの基準を当てはめた「目安」と書く。
