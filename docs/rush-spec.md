# アニソン激アツRUSH（仕様書・案）

## 目的
イントロクイズに、パチンコ・パチスロの「保留・リーチ・大当たり・確変（RUSH）」の盛り上がりを重ねる。
正解した瞬間の気持ちよさを、演出（色・カットイン・炎・連チャン）で何倍にもする。お金や課金は一切なく、動くのは得点だけ。

## 遊び方の流れ（遊び方の1つ「激アツRUSH」）
全員が同じ問題に同時に答える（ふつうのモードと同じ）。1問ごとに、次の順で進む。

1. **保留（問題が出る前）**
   - その問題の「熱さ」が、保留ランプの色で先に出る。
   - 色と、当たりやすさ（目安）：青 5%（ふつう）／緑 15%／赤 40%／金 75%／虹 100%（全回転・確定）
   - 色が出る確率：青 66%／緑 20%／赤 9%／金 4%／虹 1%
   - 先の問題の色も、ランプで4つ先まで見える（次はあつそう、と分かる）。
   - **ゲームを始めるときに、全部の問題の色と当たりを決める**（サーバーが「当たり表」を作る）。当たりの問題には、その場でパチスロの曲を入れておく。
     こうすると、ランプは当たり表をそのまま映すだけになり、途中で読み込み直した人にも同じものが出せる。
2. **リーチ（当たりの問題だけ）**
   - 当たりの問題では、サビ（ヒント）に入るところで「リーチ！」のカットインが出る。
   - 当たりの問題は、パチンコ・パチスロの台に使われた曲（「パチスロで有名」の曲）から出す。
3. **大当たり**
   - 当たりの問題に正解した人は「大当たり！」。ボーナス +2000点（固定）。
   - 同時に、その人だけ **RUSH** に入る。
4. **RUSH（確変）**
   - 大当たりした人の、次の問題から始まる。人ごとに別々。
   - RUSH中の正解は点数が倍になる。連チャン（連続正解）が続くほど倍率が上がる：×2 → ×2.5 → ×3 → ×3.5 → ×4（上限）
   - 間違い・パス・無回答で RUSH は終わる（「RUSH終了：◯連チャン・◯点」と出る）。
   - RUSH中は最大10問まで。
5. **ハズレ**
   - 当たりの問題に間違えた人には「ハズレ…」と出る（点は入らない。RUSH中ならRUSH終了）。
6. **RUSH中に、また当たりの問題が来たとき**
   - 当たりのボーナス +2000点を足す。連チャンの倍率はそのまま続き、「あと10問」は10に戻る（延長）。

## 点数
- 基本点：ふつうのモードと同じ（早いほど500〜1000点）。サビに入ってからは ×0.7。
- 大当たり：基本点 +2000点。
- RUSH中：基本点 × 連チャン倍率。大当たりのボーナスは倍にしない。
- 最終問題の得点2倍・連続正解ボーナスは、設定に従う（RUSH中は連続正解ボーナスを重ねない）。
- 順位は、合計点の順。

## 画面の演出
- 保留ランプ：画面上に4つ（青・緑・赤・金・虹の色）。次の問題が一番左。
- 当たり問題：背景が赤く光り、「リーチ！」のカットイン（キャラが出る）。
- 大当たり：「大当たり！」のカットイン、紙吹雪、画面が金色に。
- RUSH中：名前の横に炎マークと倍率（×2.5）。背景が燃える。連チャンのたびに数字がはねる。
- 全回転（虹）：サビを最大の音で流し、画面を虹色に。
- 結果画面：大当たり回数・いちばん長い連チャン・RUSHで稼いだ点数。
- 称号：「RUSH王」（最長連チャン）、「引き強」（大当たり回数）、「全回転」（虹で当てた人）。

## 設定（ロビー）
- 「激アツRUSH」を遊び方に追加。
- 「当たりやすさ」：ふつう／出やすい（各色の当たり率を1.5倍）／出にくい（0.6倍）。初めは「ふつう」。
- 問題数：いまの選択肢（5・10・20・30問）をそのまま使う。初めは20問（RUSHに入る余裕があるため）。
- チーム戦は使えない。
- ゲームの途中で設定を変えても、当たり表は作り直さない（出題の組み直しを止める）。

## 作る場所（技術メモ）
- server.js：遊び方 `rush` を追加。1問ごとに色と当たりをサーバーが決める（画面では決めない）。
  当たりのときは、その部屋の出題できる曲から「パチスロで有名」の曲を選んで、その問題の曲にする（足りなければふつうの問題）。
- onAnswer：RUSH中の倍率と大当たりのボーナスを、サーバーで計算する。reveal で結果を送る。
- クライアント（app.js・style.css・index.html）：保留ランプ・カットイン・RUSH表示。既存の charFx.cutin と flash を使う。
- 称号は titlesOf に足す。
- ゲーム開始時（startGame）に、全問の色・当たりを決めた「当たり表」と、当たりに入れるパチスロの曲を作る。出題の組み直し（途中で設定を変えたとき）は、出題者・ビンゴと同じように止める。
- テスト：3001番で2人。テスト用の環境変数（`RUSH_FORCE=hit`）で、全問を当たりにできるようにする（本番では使わない）。

## 決まったこと（2026-10-10）
1. 名前：**アニソン激アツRUSH**
2. 人数：**1人用も複数人も両方遊べる**（RUSHは人ごと。1人でも同じように動く）
3. 当たり問題の曲：**パチスロで有名な曲だけ**（「パチスロで有名」のジャンルの曲）
