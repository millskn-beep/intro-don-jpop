# アニソン指パチンコ（play: sling）

- 曲が流れると、選択肢の的が画面に浮かぶ。画面下のパチンコを引っぱって放すと弾が飛び、正解の的に当てると正解。全員同時に撃つ。
- 部屋の設定：弾の数（3発・外れの的は−100点／1発勝負／無制限・外れの的に当てたら終わり）、的の動き（ゆっくり／止まる／速い）、的の数（8／6／4、部屋の選択肢の数とは別）。
- 点数はふつうと同じ（速いほど高い、サビ以降は×0.7）。的の中心近く（CRIT）に当てると会心で +20%。
- 当たり判定は各自の画面。サーバー（slShot）は弾の数・減点・答えを決める。直接の answer は受け付けない（パスだけ）。
- 的の位置は問題ごとの slSeed と、サーバーの時計で流し始めてからの秒数で決まる（全員同じ）。サビに入ると速くなる。
- ほかの人の弾は軌跡だけ見せる（slTrail）。どの的に当たったか・割れたかは本人の画面だけ。
- 狙いの補助：的のまわり ASSIST 倍の範囲に入った弾を少し寄せる（public/sling.js の定数で調整）。
