# イントロドン！J-POP（仕様書）

## 目的
アニソンイントロ対戦（D:/AI/anison）を元にした、J-POP のイントロクイズ。スマホの縦向き専用で遊ぶ。アニソン版とは別のフォルダ・別のサイト（アニソン版には影響しない）。

## 作るもの
- 曲：ランキング（年間ヒット・カラオケ人気など）から集めた、公式MVのある有名曲。まず約1000曲、あとで増やす。最初はアニソン版にある J-POP 196曲から始める。
- データの形：アニソン版と同じ songs.json。`work`（作品）には歌手名を入れる（「この歌手の曲だけ」のお題・3つ埋めの枠・同じ歌手を続けて出さない、がそのまま使える）。
  - 曲名当てで歌手名を言っても正解にしない。ヒントの「作品」は出さない（歌手と同じになるため）。
- 遊び方：ふつう・早押し・3つ埋め（曲名・歌手・発表年）・サバイバル・協力。
- お題：年代（80〜20年代）、ジャンル（アイドル・バンド・バラード・ダンス／ボーカルグループ・シンガーソングライター・ヒップホップ・キッズ など。歌手ごとに付ける）、歌手。
- 知名度：再生回数の段階は、J-POP の曲の中での順位（割合）で決める（公式MVの再生回数はアニソンより桁が多いため）。
- 画面：スマホ縦向き（390×844 を基準）。1画面に収める（縦向きで確認）。

## 手順
1. アニソン版を複製（git clone）。曲データ・遊びの記録など J-POP に要らないデータは消す。
2. アニソン版の J-POP 196曲で、まず動くようにする（3002番で試す）。
3. 遊び方を5つにしぼり、縦向きのスマホ画面に作り直す。
4. 曲集め：Wikipedia の年間ランキングなどから候補を集め、YouTube で公式MVを探し、イントロ・サビ・再生回数・動画の長さを測る（途中経過は毎回ファイルに残す）。
5. 公開：新しい GitHub リポジトリと Render のサービスを作る（作る前に確認する）。

## 反映
- この会話（セッション）の「反映して」は J-POP 版の反映。パッチノートも書く。
- 本番の URL・GitHub のデータ保存先（datalog）・tools の SITE は J-POP 版のものに変える（アニソン版に書き込まないように）。

## 追加（2026-11-05）
1. **ひとりで遊ぶ**：最初の画面のボタンで、部屋を作る手間なしに10問始める。この部屋は公開中の部屋の一覧に出さない。
2. **ワンタップ開始**：「全部・80〜2020年代・アイドル・バンド…」のボタンで、その範囲の10問。
3. **今日の10問**：日本時間0時で切り替わる。超有名・有名の曲から日付で選び、選んだ10曲はその日のうちは変えない（曲を足しても変わらない）。記録に保存して、再起動・反映でも消えない。
4. **結果のシェア**：終わったら「今日の10問 8/10問正解 1234点」などを、スマホの共有メニュー（LINE・X など）で送る。共有メニューがない端末は文をコピーする。
5. **招待**：部屋の招待リンクを LINE で送るボタン・共有メニュー・QR コード。
6. **自分の記録**：マイページに年代別・歌手別の正解率。
7. **ランキング**：今日の10問の点数の上位（名前だけ。1人1回目の点数だけ数える）。30日分まで残す。
8. **サビの見直し一覧**：測り終わったら、サビの位置が怪しい曲を、直す順に一覧にする（docs/chorus-review.md）。
