# アニソンすごろく（すごろくレース・仕様書）

## 目的
いつものイントロクイズに答えながら、正解の速さでコマを進め、先にゴール（30マス目）に着いた人の勝ち（play `sugoroku`）。1人からでも遊べる（2人以上がおすすめ）。

## 進み方（毎問の答え合わせのとき）
- 正解の速い順に：1番 3マス／2番 2マス／ほかの正解 1マス。不正解・パスは進まない。
- 「1回休み」の人は、その問題は進まない（休みが終わる）。「次は2倍」の人は進むマスが2倍。

## イベントマス（止まったマスで1回だけ起きる）
- ⏩ +2マス進む／⏪ 2マス戻る
- 💰 ボーナス +300点
- 💤 1回休み（次に正解しても進まない）
- ✖2 次に進むマスが2倍
- 🔀 先頭の人と場所を入れ替え（自分が先頭なら何もない）
- 💥 すぐ前の人を2マス戻す
- マスの並びはゲームごとにランダム（スタート直後とゴール直前はイベントなし）。

## 終わり
- だれかがゴールしたら、その問題で終わり（ゴールした人 +2000点）。最大60問。
- 順位は、進んだマスの多い順（同じなら得点）。

## 画面
- クイズ画面の下に、すごろくの盤（31マス・2段）と全員のコマを小さく出す（1画面に収める）。
- イベントは答え合わせの「ハイライト」に出す。

## 実装
- server.js：game.sg（board・pos・rest・dbl）、sgReveal（答え合わせで呼ぶ）、publicRoom の `sugoroku`、終わりの判定と順位。
- public/app.js：renderSugoroku（#sgBox）。
