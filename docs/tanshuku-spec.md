# アニソン短縮鉄道（play: 'tanshuku'）

はねるのトびら「短縮鉄道の夜」のアニソン版。略称を見て、元の名前を答える。

## 流れ
- 参加者の順番をシャッフルして、1人ずつ答える（ほかの人は見ているだけ）
- お題（tsKind）：アニメと歌手（both）／アニメだけ／歌手だけ／一般の略称だけ（general）／ぜんぶ（all）
- 答え方（tsAns）
  - 4択（choice）：正解＋名前が似ているもの2つ（ひっかけ）＋ほかの1つ。一般の略称は同じ分野の中から。制限 6秒→1周ごとに0.5秒短く（最短2.5秒）
  - 手打ち（type）：かな・カナ・全角半角・記号・空白の違いは無視。正式名称か読み（yomi）と1〜2文字の違いまでは正解。制限 15秒→1秒ずつ短く（最短8秒）
  - VC（vc）：口で答える。正解は答える人以外に見えて、だれか1人が⭕／❌を押す。1人で遊ぶときは「答えを見る」→自分で判定。制限 8秒→0.5秒ずつ（最短4秒）、判定は時間のあと10秒まで待つ（押されなければ時間切れ）
- 正解：+100点。アニメ・歌手はその作品・歌手のいちばん聴かれている曲を5秒流す。一般の略称は効果音（ピンポン）だけ
- 間違い・時間切れ：脱落（ブブー）。最後の1人が勝ち（+1000点）
- 1人で遊ぶときは、間違えるまで続ける（最大300問）

## データ
- data/abbrev.json：[{ kind: 'work'|'artist'|'general', cat?: 'shop'|'daily'|'net'|'tv', abbr, full, yomi }]。実際に使われている略称だけ
