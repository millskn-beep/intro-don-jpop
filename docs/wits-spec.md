# アニソン年当てベット（ウィッツ＆ウェイジャーズ風・仕様書）

## 目的
イントロを聴いて**発売年**を予想し、並んだ予想の中から「どれがいちばん近いか」に賭ける遊び方（play `wits`）。知らない曲でも、ほかの人の予想に賭けて勝てる。2人以上（3人以上がおすすめ）。

## 1問の流れ
1. **予想（35秒）**：イントロが流れる（約25秒）。発売年（1960〜今年）を入力して出す。全員出したら次へ。
2. **賭け（30秒）**：出た予想を年の順に並べ、左端に「全員より古い」の枠を足す。マーカー2個を、好きな枠に置く（同じ枠に2個でもよい）。各マーカーには、追加で点数を上乗せできる（0／200／500点。外れると失う）。
3. **結果**：正解の年を公開。**正解の年を超えない中でいちばん近い予想の枠**が当たり（全部の予想が新しすぎたら「全員より古い」が当たり）。
   - 当たったマーカー：（100＋上乗せ）×倍率 の点
   - 外れたマーカー：上乗せした点を失う
   - 当たった枠の予想を出した人：+300点（ぴったりなら +600点）

## 倍率
- 真ん中の枠 2倍、そこから外へ 3倍・4倍・5倍、「全員より古い」は 6倍。

## 細かいきまり
- 同じ年の予想は1つの枠にまとめる。
- 時間切れで予想を出さなかった人も、賭けには参加できる。マーカーを置かなかった人は賭けなし。
- 点数は 0 より下がらない。
- 1画面に収める。

## 実装
- server.js：startWitsRound・wwStep・wwFinish、socket `wwGuess`／`wwBet`。場は `wwPhase`（全員）。
- イントロは人狼と同じ `wolfSong` で全員に流す。
