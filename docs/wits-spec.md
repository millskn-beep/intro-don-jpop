# 年代ベット・アニソンベット（仕様書）

別々の遊び方：**年代ベット**（play `wits`）と**アニソンベット**（play `bluff`）。曲の流れや賭けのしくみは共通（server.js の ww〜）。

# 年代ベット（ウィッツ＆ウェイジャーズ風）

## 目的
イントロを聴いて**発売年**を予想し、並んだ予想の中から「どれがいちばん近いか」に賭ける遊び方（play `wits`）。知らない曲でも、ほかの人の予想に賭けて勝てる。2人以上（3人以上がおすすめ）。

## 1問の流れ
1. **予想（35秒）**：イントロが流れる（約25秒）。発売年（1960〜今年）を入力して出す。全員出したら次へ。
2. **賭け（30秒）**：出た予想を年の順に並べ、左端に「全員より古い」の枠を足す。マーカー2個を、好きな枠に置く（同じ枠に2個でもよい）。各マーカーには、追加で点数を上乗せできる（0／200／500点。外れると失う）。
3. **結果**：正解の年を公開。**正解の年にいちばん近い予想の枠**が当たり（正解より新しい予想でもよい。同じ近さなら古いほう。全部の予想が正解より新しければ「全員より古い」が当たり）。
   - 当たったマーカー：（100＋上乗せ）×倍率 の点
   - 外れたマーカー：上乗せした点を失う
   - 当たった枠の予想を出した人：+300点（ぴったりなら +600点）

## 倍率
- 真ん中の枠 2倍、そこから外へ 3倍・4倍・5倍、「全員より古い」は 6倍。

## 細かいきまり
- 同じ年の予想は1つの枠にまとめる。
- 時間切れで予想を出さなかった人も、賭けには参加できる。マーカーを置かなかった人は賭けなし。
- 点数は 0 より下がらない。
- 1画面に収める。

# アニソンベット（play `bluff`）
出すもの（`wwHint`）：曲名／イントロだけ／曲名と歌手。検索は作品名・曲名・歌手名（ひらがなも可）。画面に出ている曲は、曲名で探しても出さない。
1. **作品を選ぶ（45秒）**：イントロを聴きながら、本物だと思わせる別の作品を検索して一覧から選ぶ。自由入力はなし。名前はシリーズの名前だけ（2期・3作目の番号なし）。本物を選ぶと選び直し（点なし）。
2. **賭け（30秒）**：本物・みんなの作品・前後の年の実在の作品をまぜて最低4枠。結果までだれの作品か伏せる。自分の作品には置けない。マーカー2個・上乗せは年と同じ。
3. **結果**：本物に賭けると（100＋上乗せ）×3倍。ほかの枠は上乗せを失い、その枠を出した人にマーカー1個につき +300点。
- ボカロなど作品名がない曲は使わない。曲名を出す設定では、曲名と作品名がほぼ同じ曲も使わない（別の曲に替える。替えがなければ年代で出す）。

## 実装
- server.js：startWitsRound・wwStep・wwFinish、socket `wwGuess`／`wwBet`。場は `wwPhase`（全員）。
- イントロは人狼と同じ `wolfSong` で全員に流す。
