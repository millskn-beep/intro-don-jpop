# アニソン人狼（仕様書）

## 目的
ワードウルフのように、1人だけ別の曲を聴いた人（人狼）を、ヒントと話し合いで見つける遊び方（play `wolf`）。3人以上。

## 1回の流れ（問題数＝回数）
1. **聴く（25秒）**：全員に曲のサビあたりが流れる。1人（人狼・ランダム）だけ、同じ作品の別の曲（なければ同じジャンル・近い年代の曲）。人狼も自分が人狼だとは知らない。
2. **ヒント（40秒）**：曲について一言（20文字まで）。全員出したら次へ。
3. **話し合い（90秒）**：全員のヒントを見ながら、アプリの中のチャットで話す（60文字まで）。全員が「投票へ進む」を押すか、時間で次へ。
4. **投票（30秒）**：人狼だと思う人に投票（自分以外）。いちばん票の多い人が1人だけで、それが人狼なら「当てた」。同票・外れなら人狼の勝ち。
5. **逆転（25秒）**：当てられた人狼は、みんなの曲を8択で当てれば逆転勝ち。
6. **結果**：両方の曲・人狼・票数を見せる。勝った側に点数（村人 +1000点／人狼 +2000点）。自動で次の回へ（12秒以上）。

## 細かいきまり
- 人狼の曲は、マイページの「もう聞きたくない」曲を避ける。
- 抜けた人は待たない（ヒント・話し合い・投票は、つながっている人だけそろえば進む）。
- 再接続した人には、いまの段階を送り直す（聴く段階なら曲も）。
- チーム戦はなし。点数の多い順が順位。

## 実装
- server.js：startWolfRound（nextQuestion から）・wolfStep（段階とタイマー）・wolfTally・wolfFinish、socket `wolfHint`／`wolfChat`／`wolfReady`／`wolfVote`／`wolfGuess`。
- 画面：画面の上に出す専用の窓（#wolfPop）。曲は各自の端末で `wolfSong` を受けて流す。
